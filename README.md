# Jack叔叔 Skill

按 Jack叔叔（Jack要加油）公开内容整理的财富观与人生观陪练 Skill，可直接给 Grok Bot / Claude 等助手加载使用。

## 文件

- `SKILL.md`：Skill 本体（人格、硬边界、思想内核、金句库）
- `Jack叔叔思想全书.md`：基于公开转写样本整理的思想全书（样本版）

## 使用方式

把 `SKILL.md` 放进助手的 workflows / skills 目录，或在对话里引用本仓库。
